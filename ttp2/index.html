ThreadsToolsPro2

Threads 自動投稿 Web アプリケーション

Meta社のSNS「Threads」への投稿を自動化するWebアプリ。
Googleアカウントでログインし、定期投稿のスケジューリングや投稿キュー管理が行えます。

アプリを開く はじめての方はこちら

概要

ThreadsToolsPro2 は、Meta社のSNS「Threads」への投稿を自動化するためのWebアプリケーションです。定期投稿のスケジューリングや、投稿キューの管理が可能です。

主な機能

Threads OAuth連携

公式APIを使用した安全なアカウント連携。アクセストークンは暗号化して保存されます。

投稿管理

テキスト投稿の作成・編集・削除に対応。投稿内容を一元的に管理できます。

定期投稿

指定した時間帯に自動投稿をスケジュール。間隔と時間帯を細かく設定できます。

ツリー投稿

1件目に返信をつなげて、最大10件の連投スレッドを自動投稿。定期・ランダム・予約投稿で使えます（有料プラン）。

投稿キュー

投稿を順番に管理し、自動的に処理。完了後にループ実行も可能です。

クラウド対応

Vercelでホスティングし24時間稼働。PCを起動していなくても投稿が実行されます。

ユーザー登録

●

はじめに（Googleログインで利用）

ThreadsToolsPro2 は Googleアカウント（Gmail）でログイン します。初めて利用する方は、先に「ユーザー登録フォーム」から、ログインに使う Gmail を登録してください（Stripe で有料プランにお申し込みの方は登録フォームは不要です）。

重要（有料版）

有料版は決済済みのお客様のみご利用いただけます。

  • Stripe でお申し込みの方（2026年10月31日以降）: 登録フォームは不要です。決済に使ったメールアドレスの Google アカウントでログインすると、そのまま有料プランになります。
  • theapps でお申し込みの方: 登録フォームのURLは決済完了時にメール等でご案内します（本ページには掲載していません）。案内が見当たらない場合は最下部の窓口へご連絡ください。
無料版について

無料版もご用意しています（連携1アカウント・月500投稿まで）。無料版の登録は、ログインページに表示される 「無料版 登録フォームを開く」 から行えます。フォーム送信後、数分で登録した Gmail でログインできるようになります。有料版へアップグレードした場合は、反映のため一度ログアウトして再ログインしてください。

登録の手順

【有料版・Stripe でお申し込みの方】

  1. 決済画面で Threadsのユーザー名 を入力して申し込む（30日無料クーポンは初回のお申し込みだけ使えます）
  2. ログインページから、決済に使ったメールアドレスの Google アカウントでログイン（別のメールアドレスでは有料プランになりません）
  3. 運営から届く Threadsテスター招待を承認 して、Threadsアカウントを連携

【有料版・theapps でお申し込みの方】

  1. 決済完了時にご案内する 専用の登録フォーム を開く
  2. メールアドレス（ログインに使う Gmail）・氏名・知ったきっかけ を入力して送信
  3. 登録完了の確認メールが届きます（送信元: ThreadsToolsPro2）
  4. 登録した Google アカウントで、そのままログインできるようになります

【無料版】

  1. ログインページの 「無料版 登録フォームを開く」 ボタンから登録フォームを開く
  2. メールアドレス（ログインに使う Gmail）とアンケートに回答して送信
  3. 登録完了の確認メールが届き、登録した Google アカウントでログインできるようになります

アカウント連携

●

Threadsアカウントを連携

連携手順

  1. サイドバーから 「アカウント管理」 をクリック
  2. 「アカウントを連携」 をクリック
  3. Threadsの認証画面で 許可
  4. 連携完了
初回連携の前に

初めて連携するアカウントは、事前に運営からの「Threadsテスター招待」の承認が必要です。手順は次の「テスター招待の承認」をご覧ください。

●

テスター招待の承認（初回連携の前に必要）

Meta（Threads API）の仕様により、連携するThreadsアカウントは事前に「Threadsテスター」として招待→承認が必要です。ご利用登録後、運営からご利用のThreadsアカウント宛に招待をお送りします。

承認手順（スマホのThreadsアプリ）

  1. Threadsアプリを開き、プロフィールアイコンをタップ
  2. 右上の 設定（⚙） → 「アカウント」 をタップ
  3. 「ウェブサイトのアクセス許可」 をタップ
  4. 「招待」 タブに表示される TheadsToolsPro2 の 「同意する」 をタップ

PCの場合は threads.com の設定 →「アカウント」→「ウェブサイトのアクセス許可」から同じ操作ができます。

承認しないとどうなる？
  • 連携時に「テスター招待の承認が必要です」というエラーが表示され、連携できません
  • 招待が表示されない場合は、Threadsアプリを最新版に更新してから開き直してください
  • 招待が届いていない場合は、お問い合わせよりご連絡ください
●

ツリー投稿のための再連携

ツリー投稿を使うには、Threadsの「返信の管理」の権限（許可画面では Manage replies and quotes on Threads posts と表示）が必要です。この機能の追加（2026年9月）より前に連携したアカウントにはこの権限がないため、アカウント管理のカードに 「ツリー未対応」 と表示されます（画面上部にも「ツリー投稿を使うには、◯件のアカウントの再連携が必要です。」と表示されます）。表示されたアカウントは、次の手順で一度だけ再連携してください。

再連携の手順

  1. 先に同じブラウザで threads.com を開き、再連携するのと同じThreadsアカウントでログインしておく
  2. サイドバーの 「アカウント管理」 を開き、「ツリー未対応」と表示されたアカウントの 「再連携」 をクリック
  3. 「〜が次へのアクセスをリクエストしています」という許可画面で、返信の管理（Manage replies and quotes on Threads posts）をオフにせず 「◯◯として続行」 をクリック
  4. アカウント管理に戻り、「ツリー未対応」の表示が消えていれば完了です
再連携のときの注意
  • 許可画面の 「アクセス許可を編集」 で、Manage replies and quotes on Threads posts（返信の管理）をオフにしないでください。オフのまま連携するとツリー投稿は使えず、「ツリー未対応」のままになります（その場合は、もう一度「再連携」からやり直してください）
  • ブラウザで別のThreadsアカウントにログインしていると、そのアカウントが新しく連携されてしまいます。必ず同じアカウントでログインしてから再連携してください
補足
  • 再連携しても、登録済みの投稿キュー・予約投稿・設定はそのまま使えます
  • 再連携するとアクセストークン（有効期限）も新しくなるため、トークンの期限切れも再連携で解消できます
  • 「ツリー未対応」の表示と「再連携」ボタンは、有料プランのときだけ表示されます
+

複数アカウント対応

アカウント管理について
  • 有料版は複数のThreadsアカウントを登録できます（無料版は1アカウントまで）
  • 投稿作成時に、どのアカウントから投稿するか選択できます
  • 同じThreadsアカウントを複数回連携することはできません
  • アクセストークンは暗号化されて安全に保存されます
無料版の制限
  • 連携できるThreadsアカウントは 1つまで
  • 投稿は 月500件まで（予約・定期・ランダム・即時投稿の合計）。上限に達した月は投稿がスキップされ、翌月に自動で再開します
  • 現在の投稿数は 設定ページ の「今月の投稿数」で確認できます
  • 制限なく利用するには有料版へのアップグレードが必要です（アップグレード後は再ログインで反映）

ツリー投稿

ご利用の前に
  • ツリー投稿は有料プラン限定です。無料プランでは「ツリー投稿は有料プラン限定です。」と案内が表示されるだけで、2件目以降は追加できません
  • Threadsの「返信の管理」の権限が必要です。この機能の追加（2026年9月）より前に連携したアカウントは「ツリー未対応」と表示されるので、先にツリー投稿のための再連携を行ってください
●

ツリー投稿とは

1件目の投稿のあとに、2件目以降を「1つ前の投稿への返信」としてつなげて投稿する機能です。Threadsでよく見る連投スレッド（例: 1件目で結論 → 2件目以降でくわしく → 最後にリンク）を、そのまま自動で投稿できます。

  • 使える画面: 定期投稿・ランダム投稿・予約投稿
  • 件数: 1つのツリーで最大10件（1件目＋返信9件）、各500文字まで
  • 画像: 2件目以降にも、1件ごとに最大10枚（JPEG・PNG・GIF・WebP、1枚5MBまで）
  • 画像プール: 画像プールの画像（ランダム画像）が付くのは1件目だけです。2件目以降の画像は、各件の「画像を追加」から直接アップロードします
  • くり返し投稿: 定期投稿・ランダム投稿では、同じ投稿が周回して投稿されるたびに、ツリー全体を1件目から投稿します
✎

ツリーの作り方

  1. 定期投稿・ランダム投稿は 「キューに追加」、予約投稿は 「新規予約投稿」 をクリックして作成画面を開く（予約投稿は、先に投稿アカウントと予約日時を選びます）
  2. 1件目の本文（必要なら画像も）を入力する
  3. 1件目の画像欄の下にある「ツリー投稿（2件目以降）」の 「ツリーに投稿を追加」 をクリック → 2件目の入力欄が追加されます（クリックするたびに1件ずつ増え、10件目まで追加できます）
  4. 各件の本文を入力し、画像を付けるときは 「画像を追加」 をクリック
  5. 順番は ↑ / ↓ ボタンで入れ替え、不要な件は ゴミ箱 ボタンで削除する
  6. ボタンが 「追加（3件）」（予約投稿は 「予約する（3件）」）のように件数付きの表示になっていることを確認してクリック
入力のポイント
  • 「ツリー投稿（2件目以降）」の右側に、1件目を含めた件数が 「ツリー 3/10件」 のように表示されます
  • 本文が空の件があると保存できません（「2件目の投稿内容を入力してください」のように表示されます）。使わない件はゴミ箱で削除してください
  • あとから2件目以降を追加・修正するときは、定期投稿・ランダム投稿は投稿の 「…」メニュー →「編集」、予約投稿は一覧の 「ツリー」 ボタンから行えます
▶

一覧での表示と、途中で失敗したときの再開

一覧での表示

  • ツリーの投稿には 「🧵 ツリー 3件」 が表示されます。クリックすると2件目以降の内容を開いて確認できます
  • ツリーは1件ずつ順番に投稿されます。投稿中はステータスが 「投稿中 2/5」（5件中2件まで投稿済み）のように表示され、その間は 編集・削除・今すぐ投稿 ができません
  • 1件目が投稿されると、「1件目をThreadsで開く」 からThreads上の実際の投稿を確認できます
  • 「今すぐ投稿」でも、ツリー全体を1件目から投稿します。件数が多いと「投稿を開始しました。続きはバックグラウンドで投稿されます。」と表示され、残りは自動で投稿されます（一覧の表示が変わらないときは、ページを再読み込みしてください）

途中で失敗したとき

ツリーの途中で失敗すると、ステータスが 「失敗 2/5」 になり、ツリーの欄に、どの件で失敗したかと理由が次のように表示されます。

ツリーの3件目で失敗しました（2件目まで投稿済み）: 〈失敗の理由〉

理由を確認して原因を解消したら、「再開（3件目から）」 をクリックします（ツリーの欄のボタン。定期投稿・ランダム投稿は「…」メニューにもあります）。投稿済みの分は出し直さず、続きの件から返信をつなげて投稿します。「今すぐ投稿」は1件目から投稿し直すので、続きを投稿したいときは「再開」を使ってください。理由ごとの対処はトラブルシューティングをご覧ください。

途中で失敗したツリーを直すとき

  • 投稿済みの件は編集できません（「投稿済み」と表示され、変更できない状態になります）
  • 定期投稿・ランダム投稿: 「編集」画面で 「途中経過を破棄して編集する」 を選ぶと、全件を編集できます。この場合、次回は1件目から投稿し直します（すでに投稿された分はThreadsに残るので、必要に応じてThreads上で削除してください）
  • 予約投稿（1回きりの投稿）: 途中経過は破棄できません。「ツリー」ボタンから未投稿の件を直してから「再開」してください

一括取り込み（CSV／スプレッドシート）

●

スプレッドシートから投稿をまとめて追加

定期投稿・ランダム投稿画面の 「一括取り込み」タブ から、Google スプレッドシート / Excel / CSV の投稿文と画像をまとめて投稿キューに追加できます。ファイルのアップロードではなく、セルをコピーして貼り付ける方式です。

シートの作り方

  • A列: 投稿文（必須、500文字まで。ツリーの場合は1件目）
  • B列: 選択中アカウントの画像プールにあるファイル名（任意。1件目に付きます。例: 1.jpg）
  • C〜K列: ツリー投稿の2〜10件目（任意・有料プラン限定。各500文字以内、テキストのみ）

1行が1投稿です。投稿文［Tab］画像ファイル名 の2列を1行ずつ用意し、ツリーにしたい行だけ、C列から右へ2件目・3件目…と続けて入力します。C列が空の行は、これまでどおり1件だけの投稿として登録されます。先頭の「文章 / 画像ファイル名」ヘッダー（C列以降は「2件目」「3件目」など）はあってもなくても構いません。B列を空欄にすると本文のみで登録されます。

入力例（4投稿分）
  1. A列 あいうえお ／ B列 1.jpg
  2. A列 かきくけこ ／ B列 空欄（画像なし）
  3. A列 さしすせそ ／ B列 2.jpg
  4. A列 Threadsで伸びる3つのコツ🧵 ／ B列 3.jpg ／ C列 ① 1行目で言い切る ／ D列 ② 数字を入れる → 3件のツリーとして登録（有料プラン）

本文と画像ファイル名を同じセルに書かず、A列とB列の別々のセルに入力してください。アプリの「解析」ボタンの下にも、入力形式と3行の例（C列＝ツリーの2件目の例つき）を常時表示しています。

取り込み手順

  1. 使用する画像を、対象アカウントの 「画像プール」 に先に登録する
  2. 定期投稿またはランダム投稿画面で アカウントを選択 し、「一括取り込み」 タブを開く
  3. スプレッドシート / Excel / CSV でA列とB列（ツリーを含む場合は、使っている列まで。最大K列）のセルを選択してコピー
  4. 「スプレッドシートの内容を貼り付け」 欄に貼り付ける
  5. 「解析」 をクリック → 投稿、画像サムネイル、照合結果が1行ずつ表示されます（ツリーの行には 「🧵 ツリー 3件」 と2件目以降の本文も表示されます）
  6. 取り込む投稿のチェックを確認（不要なものはチェックを外す。「全選択／全解除」も可）
  7. 「選択した○件を取り込む」 をクリック → 画像付きで投稿キューに追加され、キューにもサムネイルが表示されます
画像ファイル名の照合

ファイル名は、選択中アカウントの画像プール内で大文字・小文字を区別して完全一致する必要があります。画像が見つからない場合や同名画像が複数ある場合は、その行が赤字で表示され、取り込み対象にできません。サムネイルと「紐付けOK」を確認してから登録してください。

ツリー（C〜K列）を取り込むとき
  • 2件目以降（C列以降）を含む行は有料プラン限定です。無料プランや「ツリー未対応」のアカウントでは、その行は赤字で表示され、取り込めません（C列が空の行はこれまでどおり取り込めます）。
  • C〜K列は各500文字以内・テキストのみです。2件目以降の画像は、取り込んだあとに投稿キューの「…」メニュー →「編集」から追加してください。
  • 途中に空欄があるとエラーになります（例: C列が空で、D列に値がある行）。C〜K列は左から詰めて入力してください（右側が空欄なのは問題ありません）。
  • L列以降に値がある行もエラーになります（ツリーは10件目＝K列まで）。
注意
  • 1投稿は500文字まで。500文字以内の投稿は最初から選択済みになります。
  • 500文字を超える投稿は取り込めません（赤字表示され、対象外になります）。一度に登録できるのは最大200件（200行）で、ツリーの行も1行で1件と数えます。
  • 画像を指定した投稿は、その投稿に紐付けた画像が優先されます。画像プールからランダムな別画像へ置き換わることはありません。
  • 従来どおり投稿文だけを1列で貼り付けることもできます。文章の自動分割を使う場合は、投稿ごとにセルを分けるか間に空行を入れてください。
  • 取り込み後は 「投稿キュー」タブ に追加されるので、必要に応じて並び順や内容を調整してください。

プロキシ設定

●

アカウントごとにプロキシ経由で投稿

定期投稿画面の 「プロキシ」タブ から、Threadsアカウントごとにプロキシを設定できます。設定すると、そのアカウントの投稿がプロキシ経由で送信されます（未設定の場合は直接接続）。

設定手順

  1. 定期投稿画面で対象の アカウントを選択 し、「プロキシ」 タブを開く
  2. 「プロキシURL」 を入力する（例: http://user:pass@host:8080）
  3. 「接続テスト」 でプロキシ経由の疎通を確認（成功すると「接続成功」と表示）
  4. 問題なければ 「保存」 をクリック（保存時に暗号化され、以降はパスワードがマスク表示されます）
  5. 不要になったら 「設定を削除」 で直接接続に戻せます
URLの形式
  • http:// または https:// で始まる形式のみ対応（SOCKS形式は非対応）。
  • 認証が必要なプロキシは、ユーザー名・パスワードを http://ユーザー名:パスワード@ホスト:ポート の形で含めてください。
  • 保存済みのプロキシは 「現在の設定」 欄でパスワードを伏せた状態（****）で確認できます。
うまくつながらないとき

「接続失敗」と表示される場合は、URLの形式（http(s)://・ホスト・ポート・認証情報）に誤りがないか、プロキシ自体が稼働しているかをご確認のうえ、再度 「接続テスト」 を実行してください。

トラブルシューティング

Qログインできません

A. 以下をご確認ください。

  1. 登録フォームでの登録が完了しているか（確認メールが届いているか）
  2. ログインに使う Googleアカウント（Gmail） が登録したアドレスと一致しているか
  3. 登録直後は反映に数分かかることがあります。少し時間をおいて再度お試しください
Q確認メールが届きません

A. 以下をご確認ください。

  1. 迷惑メールフォルダを確認
  2. 登録フォームに入力したメールアドレスにタイプミスがないか確認
  3. 改善しない場合は下記の窓口へご連絡ください
QThreadsアカウントが連携できません

A. 以下をご確認ください。

  1. 運営からの「Threadsテスター招待」を承認済みか確認（承認手順はこちら）
  2. Threadsの認証画面で許可したか確認
  3. 同じThreadsアカウントを重複連携していないか確認
  4. 一度ログアウトして再度連携をお試しください
Q連携時に「テスター招待の承認が必要です」または「トークンの取得に失敗しました」と表示されます

A. 連携するThreadsアカウントが、運営からの「Threadsテスター招待」を未承認のときに表示されます。Threadsアプリの 設定（⚙）→「アカウント」→「ウェブサイトのアクセス許可」→「招待」タブ で TheadsToolsPro2 の 「同意する」 をタップしてから、もう一度連携をお試しください（画像つきの承認手順はこちら）。

  1. 招待が表示されない場合は、Threadsアプリを最新版に更新して開き直してください
  2. それでも招待が見当たらない場合は、招待が未送信の可能性があります。お問い合わせより、ご利用のThreadsユーザーネームを添えてご連絡ください
Q「アカウントを連携」を押すと、許可画面ではなくInstagramのページに飛ばされます

A. お使いのブラウザで Threads にログインしていないときに起こる Meta 側の挙動です（アプリの不具合ではありません）。未ログインのまま連携ボタンを押すと Threads のログインページへ転送され、そこから Instagram のログインに進む途中で通常の Instagram 画面に着地してしまいます。以下の手順でお試しください。

  1. 先に同じブラウザで threads.com を開き、連携したいアカウントでログインしておく
  2. Instagram アカウントに Threads プロフィールを未作成の場合は、先に Threads でプロフィールを作成する（プロフィールがないと連携できません）
  3. 本アプリに戻り、再度 「アカウントを連携」 をクリック
  4. 「ThreadsToolsPro2 が次へのアクセスをリクエストしています」という許可画面が表示されたら、「◯◯として続行」 ボタンをクリック → これだけで連携完了です
補足
  • 連携ボタンを押すと新しいタブは開かず、同じタブのまま Threads の認証ページへ移動します（正常な動作です）。
  • スマホでは Instagram / Threads アプリが自動で開いてしまい、うまく連携できないことがあります。PC のブラウザからの連携をおすすめします。
Q「このアカウントはツリー投稿の権限がありません」と表示されます

A. そのThreadsアカウントに、ツリー投稿に必要な「返信の管理」の権限がないときに表示されます。この機能の追加（2026年9月）より前に連携したアカウントや、連携時に「アクセス許可を編集」で返信の管理をオフにしたアカウントが対象で、再連携すると使えるようになります（再連携の手順はこちら）。

  1. 先に同じブラウザで threads.com を開き、そのThreadsアカウントでログインしておく
  2. 「アカウント管理」 で、「ツリー未対応」と表示されたアカウントの 「再連携」 をクリックし、返信の管理をオフにせずに許可する
  3. 「ツリー未対応」の表示が消えたら完了です。一覧で「失敗」になっているツリーは、「再開」 で投稿できます
Qツリーが途中で失敗しました（「失敗 2/5」と表示されます）

A. 一覧のツリーの欄に、「ツリーの3件目で失敗しました（2件目まで投稿済み）: 〈理由〉」 のように、失敗した件と理由が表示されます。理由を確認して原因を解消してから、「再開（3件目から）」 をクリックしてください。投稿済みの分は出し直さず、続きの件から投稿します。

  1. 理由が 「Threadsの投稿上限に達しました」 や 「返信の上限（24時間で1,000件）に達しています」 のとき：Threadsの上限（24時間で投稿250件・返信1,000件）に達しています。時間をおいてから再開してください
  2. 理由が 「アクセストークンが無効です」 や 「返信の権限がありません」 のとき：トークンの期限切れや権限不足です。再連携してから再開してください
  3. それ以外の理由（Threadsからのエラー内容）のとき：本文や画像を見直し、未投稿の件を直してから再開してください（投稿済みの件は変更できません）
