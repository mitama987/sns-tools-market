Facebook の交流づくりを、毎日ちょっとずつ時短。

タイムラインやページの投稿へのいいねを、決めた間隔で自動にする Windows 用ソフトです。

01できること

  • 投稿へのいいねを自動にタイムラインやページの投稿に、決めた間隔でいいね。交流のきっかけづくりを手放せます。
  • 複数アカウントを管理アカウントを登録して切り替えながら使えます。
  • 動いている様子が見える実行状況が画面に出るので、止まっていないかすぐ分かります。

02使い方

  1. 購入後のメールにあるフォルダから FacebookToolsPro の exe をダウンロードしてデスクトップに保存
  2. exe をダブルクリックして起動（Windows の警告が出たら「詳細情報」→「実行」）
  3. 最初の画面で、ご登録のメールアドレスを入力してログイン
  4. 手順書の「アカウント管理」で Facebook アカウントを追加し、「自動いいね」で間隔と回数を決めて開始
