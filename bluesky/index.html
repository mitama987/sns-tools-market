Blueskyの運用ツール

Bluesky の投稿を、スプレッドシートにおまかせ。

Google スプレッドシートに書いた投稿を、決めた間隔で Bluesky へ自動投稿します。PC の電源は不要です。

¥3,000税込・買い切り（月額なし）
購入する 使い方を見る
作った本人が販売・サポート ／ クレジットカード（分割可）・Apple Pay・Google Pay・銀行振込・PayPay（決済は Stripe）

01できること

  • 書くだけで投稿予約「定期投稿」シートに投稿文を並べるだけ。
  • 1〜12 時間おきに自動投稿間隔は 1・2・4・6・8・12 時間から選べます。
  • まんべんなく投稿投稿回数がいちばん少ない文から順に出すので、同じ文ばかりになりません。

02使い方

  1. 購入後のメールのリンクを開いて「コピーを作成」（ご自身の Google ドライブに保存されます。元のシートは使わないでください）
  2. Bluesky の 設定 → プライバシーとセキュリティ → アプリパスワード で App password を発行して控える
  3. コピーしたシートの「初期設定」に Bluesky のユーザー ID と App password、「定期投稿」の A 列に投稿文を入れる
  4. 「定期設定」で間隔（1・2・4・6・8・12 時間）を選び、上のメニュー「⚡Bluesky投稿」→「定期実行を開始」

件数や間隔は安全寄りの既定値にしていますが、各サービスによる制限・停止が起きないことは保証できません。少ない件数から、ご自身の判断の範囲でお使いください。
