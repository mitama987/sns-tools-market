noteの運用ツール

note の「スキ」での交流を、時短する。

キーワードやタグで見つけた note の記事に、決めた数だけスキを付ける Windows 用ソフトです。

01できること

  • キーワード・タグで探す検索ワードを 5 つまで登録。毎回その中からランダムに選んで記事を探します。
  • 1 回のスキの数を決める既定 10 件・上限 50 件。少ない数から始められます。
  • エクセルに書くだけの設定note ID・パスワード・検索ワードをエクセルに入れて、exe を開くだけ。

02使い方

  1. 購入後のメールにあるフォルダの中身（exe・note_info_ver1.2.xlsx・手順書 2 つ）を、PC の同じフォルダにダウンロード
  2. note_info_ver1.2.xlsx の「info」シートに note ID とパスワード、「like」シートにスキの数と検索ワードを入れて保存
  3. note_auto_like_ver6.0.exe をダブルクリック（Windows の警告が出たら「詳細情報」→「実行」）。Chrome が開いて自動でスキを付けます
  4. くわしくは手順書「【最初にお読みください】初期設定（Like）」と「note_auto_like 手順書」をご覧ください
